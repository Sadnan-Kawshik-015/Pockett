# 💰 Pockett — Personal Finance Tracker

**Pockett** is a clean, modern, and intuitive personal finance tracking application designed to help users take control of their financial life. Log daily expenses, analyze spending patterns with breakdown visualizers, and monitor your budget effortlessly.

---

## ✨ Features

- **Instant Expense Logging**: Quickly record expenses with category, amount, date, and custom descriptions.
- **Spending Visualizer**: Get a clear breakdown of where your money goes across categories such as Bills, Food, Health, Transport, and more.
- **Flexible Time Period Filtering**: View transactions and summaries tailored to specific date ranges—last week, last month, or custom periods.
- **BD Taka (৳) Currency Support**: Tailored to local currency representation out of the box.
- **Authentication**: Secure user sign-in and account onboarding.

---

## 🛠️ Tech Stack

- **Frontend**: HTML,CSS,Java script
- **Icons**: Lucide Icons / FontAwesome
- **Backend / Database**: Fast API, SQLite
- **Hosting / Port**: Runs locally on `http://localhost:5001` by default

## 🚀 Getting Started

Follow these steps to set up and run **Pockett** locally on your machine.

### Prerequisites

Make sure you have Node.js (v16.x or higher) and npm/yarn installed.

```bash
node -v
npm -v
```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/pockett.git
   cd pockett
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` or `.env` file in the root directory and add required keys (e.g., database connection string, API URLs):
   ```env
   PORT=5001
   DATABASE_URL=your_database_url
   ```

4. **Run the Development Server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

5. Open your browser and navigate to `http://localhost:5001` to view the application!
